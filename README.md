# 휴가 쿠폰 추첨 시스템

키다리스튜디오 사원 대상 분기별 휴가 쿠폰 추첨 시스템입니다.

## 기술 스택

- **Framework**: SpringBoot 3.3
- **Database**: H2 (In-Memory/File)
- **ORM**: JPA + QueryDSL
- **Migration**: Liquibase (SQL 기반)
- **Build Tool**: Gradle 8.7
- **Java Version**: 17
- **Code Generation**: Lombok
- **Testing**: JUnit 5 + jqwik (Property-Based Testing)
